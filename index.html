JavaScript - Inicio en la Programación Funcional.

¿Qué es la Programación funcional

La programación funcional es un paradigma de programación basado en el uso de funciones para resolver problemas y procesar datos. En JavaScript, este enfoque permite escribir código más claro , reutilizable y organizado, trabajando de una manera más declarativa.

Una de las ideas principales de la programación funcional es la inmutabilidad, es decir evitar modificar directamente los datos originales y trabajar creando nuevos datos a partir de ellos. Esto permite conservar la información incial como respaldo y evitar errores producidos por cambios inesperados en el programa.

JavaScript incorpora distintas herramientas relacionadas con este paradigma, y una de las primeras que se suellen utilizar es forEach().


Método forEach()

El método forEach() permite recorrer cada elemento de un array ejectando una función sobre cada uno de ellos.

Su principal ventaja es que evita utilizar estructuras repetitivas tradicionales como for, ofreciendo una sintaxis más moderna y legible.


Sintaxis básica 
     array.forEach(function(elemento){
    //Intrucciones
    });
forEach() Recorre automáticamente cada elemento del array y ejecuta la función indicada. El parámetro elemento representa cada valor almacenado dentro del array.
Ejemplo básico 
     let numeros = [1, 2, 3];

    numeros.forEach(numero => {
        console.log(numero * 2);
    });

En este ejemplo, forEach() recorrer cada elemento del array numeros y muestra por consola el doble de cada valor. El array origital no se modifica, ya que únicamente se trabaja generando nuevos resultados a partir de sus datos. Este enfoque se relaciona con la idea de inmutabilidad utilizada en programación funcional.


Comparación con for

Forma tradicional Forma utilizando forEach() 
 let numeros = [1, 2, 3];
                    
for(let i = 0; i < numeros.length; i++){
    console.log(numeros[i] * 2);
}
 
 let numeros = [1, 2, 3];
                    
numeros.forEach(numeros.length; numero=>{
    console.log(numeros* 2);
})

Con forEach() ya no es necesario controlar índices ni condiciones de repetición manualmente. El código resulta más simple, limpio y fácil de interpretar.
